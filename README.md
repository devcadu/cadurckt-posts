# cadurckt-posts

Posts do Instagram @cadurckt gerados pelo Claude.

- `kit/` — modelos (render.py), fontes, banco de fotos e exemplos.
- `posts/AAAA-MM-DD_tema/` — slides em JPG de cada post. O Make e o Instagram leem as imagens por link público:
  `https://cdn.jsdelivr.net/gh/devcadu/cadurckt-posts@<commit>/posts/<pasta>/<arquivo>.jpg`
